Entrenamiento del modelo

Reentrena el estimador de dominio (regresión logística) con datos nuevos: cada entrenamiento simula otra población de aprendices virtuales, elige la regularización por validación cruzada agrupada por aprendiz y comprueba que no haya sobreajuste. Este botón ejecuta exactamente el mismo proceso que python -m ml.entrenar; la práctica usa el modelo nuevo desde la siguiente respuesta.
